1. KedoClaw模块
1.1 产品详情
接口地址: /Product/Detail
请求方法: GET
传递参数:
prodId: string (产品ID，例如 "kedoclaw")
返回参数:
id: string (产品ID)
name: string (产品名称，如 "KedoClaw一体机")
price: number (价格)
description: string (产品描述)
configurations: Array (可选配置列表)
images: Array (产品图片)

1.2 查询产品服务套餐
接口地址: /Order/QueryOnionProdServices
请求方法: GET
传递参数:
F_ProdId: string (产品ID，例如 "kedoclaw")
返回参数:
services: Array (服务套餐列表)，每个套餐包含：
id: string (套餐ID)
name: string (套餐名称)
price: number (套餐价格)
description: string (套餐描述)
features: Array (套餐包含的功能)

3. 我的订单模块
3.1 创建订单
接口地址: /api/orders
请求方法: POST
传递参数:
items: Array (订单商品列表)，每个商品包含：
id: string (商品ID)
name: string (商品名称)
price: number (商品价格)
quantity: number (购买数量)
config: string (配置信息)
subtotal: number (商品总额)
shippingFee: number (运费)
total: number (订单总金额)
customerInfo: Object (客户信息):
name: string (收货人姓名)
phone: string (联系电话)
address: string (收货地址)
返回参数:
id: string (订单ID)
status: string (订单状态，如 "pending")
createdAt: string (创建时间)

3.2 获取订单列表
接口地址: /api/orders
请求方法: GET
传递参数: 无
返回参数:
orders: Array (订单列表)，每个订单包含：
id: string (订单ID)
createdAt: string (创建时间)
status: string (订单状态)
total: number (订单总金额)
items: Array (订单商品列表)

3.3 获取单个订单
接口地址: /api/orders/{orderId}
请求方法: GET
传递参数:
orderId: string (订单ID)
返回参数:
id: string (订单ID)
createdAt: string (创建时间)
status: string (订单状态)
items: Array (订单商品列表)
subtotal: number (商品总额)
shippingFee: number (运费)
total: number (订单总金额)
customerInfo: Object (客户信息)
shippingInfo: Object (物流信息)

3.4 更新订单状态
接口地址: /api/orders/{orderId}/status
请求方法: PATCH
传递参数:
orderId: string (订单ID)
status: string (订单状态，如 "pending", "paid", "shipped", "completed", "cancelled")
返回参数:
success: boolean (操作是否成功)
status: string (更新后的订单状态)

3.5 取消订单
接口地址: /api/orders/{orderId}/cancel
请求方法: PATCH
传递参数:
orderId: string (订单ID)
返回参数:
success: boolean (操作是否成功)
status: string (更新后的订单状态)

4. 物流查询模块

orderId: string (	订单ID)

orderId: string (订单ID)
status: string (订单状态，如 "paid", "shipped", "completed")
返回参数:
success: boolean (操作是否成功)
status: string (更新后的订单状态)

5.4 销售统计
接口地址: /Merchant/Statistics/Sales
请求方法: GET

## 6. 技能商城模块
### 6.1 技能商店浏览
- 接口地址 ： /api/skills
- 请求方法 ：GET
- 传递参数 ：
  - category ：string (可选，技能分类)
  - keyword ：string (可选，搜索关键词)
  - page ：number (可选，页码)
  - pageSize ：number (可选，每页数量)
- 返回参数 ：
  - skills ：Array (技能列表)，每个技能包含：
    - id ：string (技能ID)
    - name ：string (技能名称)
    - description ：string (技能描述)
    - category ：string (技能分类)
    - rating ：number (技能评分)
    - icon ：string (技能图标URL)
    - installed ：boolean (是否已安装)
  - total ：number (总技能数)

### 6.2 技能分类
- 接口地址 ： /api/skills/categories
- 请求方法 ：GET
- 传递参数 ：无
- 返回参数 ：
  - categories ：Array (分类列表)，每个分类包含：
    - id ：string (分类ID)
    - name ：string (分类名称)

### 6.3 安装技能
- 接口地址 ： /api/skills/install
- 请求方法 ：POST
- 传递参数 ：
  - skillId ：string (技能ID)
  - userId ：string (用户ID)
- 返回参数 ：
  - success ：boolean (操作是否成功)
  - skill ：object (安装的技能信息)

### 6.4 卸载技能
- 接口地址 ： /api/skills/uninstall
- 请求方法 ：POST
- 传递参数 ：
  - skillId ：string (技能ID)
  - userId ：string (用户ID)
- 返回参数 ：
  - success ：boolean (操作是否成功)

### 6.5 我的技能
- 接口地址 ： /api/skills/my
- 请求方法 ：GET
- 传递参数 ：
  - userId ：string (用户ID)
  - type ：string (可选，技能类型：added/created)
  - keyword ：string (可选，搜索关键词)
- 返回参数 ：
  - skills ：Array (技能列表)，每个技能包含：
    - id ：string (技能ID)
    - name ：string (技能名称)
    - description ：string (技能描述)
    - icon ：string (技能图标URL)
    - type ：string (技能类型)
    - createdAt ：string (创建时间)

### 6.6 创建技能
- 接口地址 ： /api/skills
- 请求方法 ：POST
- 传递参数 ：
  - userId ：string (用户ID)
  - name ：string (技能名称)
  - description ：string (技能描述)
  - category ：string (技能分类)
  - config ：object (技能配置)
- 返回参数 ：
  - success ：boolean (操作是否成功)
  - skill ：object (创建的技能信息)

### 6.7 编辑技能
- 接口地址 ： /api/skills/{skillId}
- 请求方法 ：PUT
- 传递参数 ：
  - skillId ：string (技能ID，路径参数)
  - name ：string (技能名称)
  - description ：string (技能描述)
  - category ：string (技能分类)
  - config ：object (技能配置)
- 返回参数 ：
  - success ：boolean (操作是否成功)
  - skill ：object (更新后的技能信息)

### 6.8 移除技能
- 接口地址 ： /api/skills/{skillId}
- 请求方法 ：DELETE
- 传递参数 ：
  - skillId ：string (技能ID，路径参数)
  - userId ：string (用户ID)
- 返回参数 ：
  - success ：boolean (操作是否成功)

### 6.9 购买记录
- 接口地址 ： /api/skills/purchase-history
- 请求方法 ：GET
- 传递参数 ：
  - userId ：string (用户ID)
  - page ：number (可选，页码)
  - pageSize ：number (可选，每页数量)
- 返回参数 ：
  - records ：Array (购买记录列表)，每条记录包含：
    - id ：string (记录ID)
    - skillId ：string (技能ID)
    - skillName ：string (技能名称)
    - price ：number (购买价格)
    - purchaseTime ：string (购买时间)
  - total ：number (总记录数)
